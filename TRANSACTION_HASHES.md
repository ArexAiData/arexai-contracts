# Deployment transaction hashes

The deployment transaction hashes were not present in the local release records used to prepare this repository and therefore are not guessed or inferred here.

Before adding a hash:

1. Open the contract's official BscScan address page.
2. Locate the **Contract Creator** record.
3. Open the linked creation transaction.
4. Confirm that the created contract address exactly matches the address in `bsc-mainnet.json`.
5. Add the transaction hash in a reviewed commit.

The transaction examples in `transactions/purchase-examples.md` are presale interactions and must not be labelled as deployment transactions.
