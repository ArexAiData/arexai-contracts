## Application source checks that passed

For each scenario: CSV parsing with blank-line source offsets; five-locale overview functions (EN/TR/DE/ES/FR); explicit approval requirement; expected aggregate calculation; original A3/A5 evidence; saved plan decoding without raw row export; rejection of a renamed unmapped column; explicit mapped second-period comparison; generated workbook structure validation.

The public CSV/JSON fixtures reproduce reference arithmetic and source coordinates only. They do not reproduce those application behaviors.

## Reporting a reproducible issue

Use only synthetic data. Include application version/source commit when known, scenario, file format, locale, device/browser, row meaning, units, blank policy, steps, expected result, actual result and source cell coordinates. State whether the issue occurred in the live application or in the public reference checker. Never post customer files, contact data, credentials or private financial records.
